# EXCEL-lent — Product Vision (source of truth)

> **Excel Data Analyst Engine**  
> *Your data analyst, built into Excel.*  
> **Upload your data. Tell us what you need. Get the analysis.**

## Philosophy

Do **not** replace Excel. **Unlock** Excel for people who do not know formulas, pivots, or charts.

Excel remains the calculation environment. EXCEL-lent is the **intelligence and orchestration layer**.

## Core flow

**Upload Data → Select What They Want → Engine Processes Data → Get Result**

## Engines

| Engine | Capability |
|--------|------------|
| Data ingestion | Excel / CSV upload, sheet detect |
| Profiling | Headers, types, missing, duplicates, roles |
| Cleaning | Duplicates, blanks, text, dates, numbers-as-text |
| Formula | SUM/AVG/…, contribution, running total, growth |
| Conditional | SUMIF, SUMIFS, COUNTIF, COUNTIFS, AVERAGEIF |
| Math | Revenue − Cost style row calculations |
| Lookup | XLOOKUP, multi-condition match, reconcile |
| Dynamic arrays | FILTER, UNIQUE, SORT |
| Dates | Day/Month/Q/FY, MoM growth, YTD |
| Pivot | Guided pivot builder |
| Charts | Bar, line, pie, donut, area |
| Dashboard | Sales / inventory / finance / CRM / HR / custom |
| Insight / Analyst mode | KPIs, top performers, alerts, recommendations |
| NL / Ask | Natural language → operations |
| Templates | Domain playbooks (Sales, Finance, CRM…) |
| Report | Executive summary + findings |
| Export | Professional multi-sheet `.xlsx` |

## One-click philosophy

Every major operation is a button. Complexity stays behind the interface.

## Long-term question the product answers

> **What would an experienced data analyst do with this dataset?**
